# Inferencia estadística y reconocimiento de patrones

Proyecto académico de aplicación de técnicas de aprendizaje supervisado y no supervisado para clasificación, regresión y clustering de datos.

## Contenido del proyecto

### Aprendizaje supervisado

- Clasificación de rotación de empleados: predicción de abandono laboral mediante SVM, Naive Bayes, LDA y QDA. Se evaluaron métricas de clasificación, curva ROC/AUC y reducción de dimensionalidad con PCA.
- Regresión logística: preprocesamiento, estandarización, partición de datos, matriz de confusión y curva ROC para evaluar el desempeño del modelo.

### Aprendizaje no supervisado

- K-Means: selección de cantidad de clusters mediante método del codo, índice de silueta y Davies-Bouldin; análisis e interpretación de segmentos.
- Clustering jerárquico: procesamiento de datos, estandarización y evaluación de agrupamientos.
- DBSCAN: ajuste de parámetros epsilon y MinPts, análisis de clusters, visualizaciones y mapa de calor.

## Técnicas y herramientas

- Python
- Jupyter Notebook
- Pandas y NumPy
- Scikit-learn
- Análisis exploratorio de datos
- Preprocesamiento y estandarización
- SVM, Naive Bayes, LDA, QDA y regresión logística
- K-Means, clustering jerárquico y DBSCAN
- PCA
- ROC/AUC, matriz de confusión, índice de silueta y Davies-Bouldin
